# ⚡ Quick Start (5 minutes)

Get Ambient Copilot running in 5 minutes.

## 1️⃣ Backend (2 minutes)

```bash
cd apps/backend

# Install
pip install -r requirements.txt

# Configure OpenAI key
cp .env.example .env
nano .env  # Add your key: OPENAI_API_KEY=sk-...

# Run
python app.py
```

✅ Keep this terminal open!

## 2️⃣ Extension (2 minutes)

1. Open Chrome
2. Go to `chrome://extensions/`
3. Turn on "Developer mode" (top right)
4. Click "Load unpacked"
5. Select `apps/extension` folder
6. Done!

## 3️⃣ Test (1 minute)

1. Visit any website
2. Click extension icon
3. Type: "What is this page about?"
4. Get response!

## 🎤 Voice Input

1. Click 🎤 button
2. Allow microphone
3. Speak your question
4. Click 🎤 to stop
5. Click Send

## 🎉 Done!

Try saying: "I prefer budget travel options"
→ It will remember and apply this preference!
